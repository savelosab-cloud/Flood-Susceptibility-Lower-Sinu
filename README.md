# Flood Susceptibility Mapping in the Lower Sinú River Basin

## Objective

Develop flood susceptibility models using Remote Sensing and Machine Learning.

## Data

- Copernicus DEM
- MERIT Hydro
- Sentinel-1 SAR
- Sentinel-2
- ESA WorldCover
- GHSL Built-up

## Models

- Random Forest
- GPBoost

## Results

RF
Accuracy = 0.903
AUC = 0.960

GPBoost
Accuracy = 0.865
AUC = 0.957
